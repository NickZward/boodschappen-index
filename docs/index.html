Het mandje vandaag (tabelweergave)
Methode: vast mandje (Laspeyres), categorie‑gewichten benaderen CBS‑bestedingsaandelen. Schapprijs = prijs zonder bonus; betaalprijs = inclusief bonus; eenheidsprijs = prijs per liter/kilo (deze beweegt ook bij krimpflatie). Dagelijkse momentopname van één winkelketen; dit is geen officiële inflatiemaatstaf. Data en code: github.com/NickZward/boodschappen-index.
